# 长期投研模型训练主线

## 目标调整

首页主结论从“下一天涨跌概率”改为长期跟踪质量、估值位置、风险等级和横截面相对排名。`direction_1d`、`direction_5d`、`return_20d`、`drawdown_20d` 保留为市场状态和短期风险辅助观察，不再作为主模型或首页核心结论。

## 训练目标

长期训练使用季度级 PIT 快照。当前四项主任务是 `excess_return_120d`、`excess_return_240d`、
`future_max_drawdown_120d` 和 `future_max_drawdown_240d`；以下质量持续性任务只能作为独立评分卡或候选实验，
不得替换四项主任务：

- `future_quality_persistence_4q`、`future_quality_persistence_8q`：未来 4/8 个季度的财务质量持续性；
- `excess_return_120d`、`excess_return_240d`：未来约 6/12 个月的市场/行业相对收益；
- `future_max_drawdown_120d`、`future_max_drawdown_240d`：未来约 6/12 个月最大回撤。

每只股票每个季度只保留最后一个可用交易日。周末和节假日不会导致季度样本丢失。财务质量标签只使用之后的 PIT 快照计算，未来数据不足时保持缺失，不向前填充。

## 特征分组

特征按质量与资产负债表、现金流与成长、估值、股东回报、行业与市场状态、宏观流动性、事件与公司行为分组。价格、波动、流动性等交易特征仅作为辅助信息。

## 模型和评估

自动队列先运行 constant、Ridge、ElasticNet、随机森林；环境具备依赖时加入 LightGBM 和 XGBoost。主要指标是 Rank IC、ICIR、Top-K 收益、Top/Bottom 差异、换手、成本后收益和回撤。验证使用季度滚动外推、purge/embargo、独立最终留出期和压力期。

## 前端输出契约

每个最新快照输出：长期质量、估值位置、长期风险、证据完整度，以及“稳健 / 观察 / 风险较高”和证据缺口。当前质量、估值、风险分是可审计的 PIT 证据评分卡；相对收益、回撤和未来质量持续性才进入训练模型。

## 当前限制

- 估值分位和行业中性估值需要在数据层补齐历史行业分位后，才能成为正式学习特征；
- 6/12/24 个月回撤恢复时间和盈利下修风险仍需补充可回溯的价格路径、财报修订和事件标签；
- 当前数据层是研究 PIT 重建，正式生产使用前仍需完成供应商可追溯性、修订链和独立最终测试审查；
- 任何模型只有在多个滚动窗口、行业、市场状态和成本敏感性下稳定，才允许进入研究结论，不以单次最高准确率替换模型。
