# 免费研究版：数据、功能与边界

此版本面向希望自行核验经营、财务、公告和风险证据的 A 股长期研究者。它提供研究工作台和可追溯数据状态，不提供买卖指令、仓位建议、目标价、收益承诺或生产级投顾服务。

## 已可使用的范围

| 能力 | 当前范围 | 使用条件 |
|---|---|---|
| 行情浏览与图表 | 已入库原始日行情 | 使用 `daily_bars_raw`；不能将原始价格替代前复权收益序列 |
| 收益研究与模型候选池 | 沪深 A 股及项目声明的基准 ETF | 同一标的必须同时有 raw 与 qfq 日行情，并继续通过历史长度、流动性、质量和样本门禁 |
| 公司/财务证据研究 | 已抓取的公告、财务字段和事件 | 必须显示来源、数据日期和缺失项；发布时间未证明时不得用于正式 PIT 历史结论 |
| 北交所及范围外标的 | 原始行情查询 | 免费版不能进入模型或收益回测，即使未来存在部分前复权响应也不能绕过该边界 |

## 当前公开数据快照

以下数字来自项目当前写入的 append-only 数据目录与质量产物；页面通过 `GET /api/v1/research-data/quality` 实时读取同一口径，而不是把这些数字写死在前端。

- 原始日行情：5,554/5,554 个当前 A 股/ETF 标的可浏览。
- 沪深 A 股与声明的 ETF 模型范围：5,216/5,216 个同时具备 raw 与前复权日行情，可进入下一层质量筛选。
- 范围外原始行情：338 个；其中 244 个没有前复权序列。它们保留在行情查询层，不能进入模型和收益回测。
- 核心财务字段当前覆盖率为 97.46%，仍低于 98% 门槛；当前 coverage artifact 记录 5,509 个股票和 418,061 条 CNINFO 公告证据。公开 Eastmoney 指标回补仅作为 research-only 增量，不改变正式 PIT 状态。财务 landing 按报告期回补并保留 SHA-256/结构审计，但总体公告到报告期匹配约 68.87%，修订链、provider 级 `available_at` 和正式 `pit_verified` 仍未证明，不能声明历史时点完全可见。
- 公司行为：162/5,549（2.92%）；不能声明全市场长周期总收益或复权一致性已完整。
- 证券生命周期：当前合并记录的上市日期、ST、上市状态覆盖约 99.66%，已知退市记录日期覆盖 100%，已知代码迁移记录完整率 100%；这些仍不是完整历史有效区间证明，不能消除幸存者偏差。
- 宏观研究级证据：央行、外汇中心和 SHIBOR 映射覆盖 5,015/5,070 条目标记录（98.92%）；统一 PIT 文件中 5,897 条观测有 **59.96%** 具备 `published_at`，另有日期级证据但没有精确时间。CPI/PPI/PMI 与 LPR 的完整发布时间/修订链仍未证明，因此宏观数据只作研究上下文，不进正式 PIT 模型特征。
- Shadow：60 个有效交易日已记录，但真实预测只覆盖 2/60 个交易日；其余记录为拒答或空预测，不能当作完整模型前向验证。

## 当前市场发现

- `GET /api/v1/research-data/discovery` 使用当前公开证券枚举提供全市场检索，而不是只显示已标准化的旧研究样本。
- 每个结果都会标记为“可进入回测/模型门禁”“仅行情研究”或“行情尚未入库”。当前 5,554 个标的均可浏览；其中 5,216 个属于免费版的沪深 A 股/基准 ETF 模型范围，338 个保留为仅行情研究。
- 该目录是**当前枚举**，不是历史成分股、退市状态或 PIT 完整性证明；把标的加入工作区不等于为它生成模型结论。

## 系统如何防止误用

1. `research_data_quality.py` 将原始行情、前复权行情、公司行为、生命周期、事件与发布时间拆开统计。
2. `GET /api/v1/research-data/eligibility/{symbol}` 返回单标的“可浏览 / 可回测 / 可进模型”状态及阻塞原因。
3. `scripts/rebuild_cn_research_pit.py` 只为同时满足 raw、qfq 和免费模型范围的标的生成标准训练层；缺 qfq 或不在沪深 A 股/基准 ETF 范围的标的会写入失败清单，不会静默以 raw 回退。
4. 前端首页先展示“免费研究版能力边界”；发现页展示当前全市场枚举和逐标的权限；数据中心再展示完整字段、覆盖率与缺失清单。
5. Agent 只有在本轮持久化了可查看的来源及 citation ID 后才会输出 `research_only` 观察；来源缺失或引用无效时会明确拒答，不以内部 evidence ID 冒充来源。

## 仍不应声称的能力

- 全市场、无幸存者偏差的历史回测；
- 完整北交所前复权、公司行为或授权行情覆盖；
- 历史财务/公告在每个决策时点都可见的正式 PIT 证明；
- 可以直接部署、自动下单或输出个股交易建议的模型。
