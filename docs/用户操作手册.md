# A 股量化研究平台：用户操作手册

这是一份只讲“怎么用”的说明。第一次使用本项目时，按顺序完成以下六步。

> 平台使用免费公开数据进行收盘后研究。页面上的概率、收益区间和风险等级均为研究结果：**非实时、非投资建议、不可直接交易**。没有商业数据授权时，正式模式显示 `blocked` 是正常行为。

## 1. 平台能做什么

平台面向 A 股日线和少量宽基 ETF，在收盘确认后运行。它会采集公开数据、审计质量、构建研究样本、训练或加载模型、冻结预测，并在未来交易日回填实际结果。

| 页面任务 | 代表的研究结果 |
| --- | --- |
| 1 日方向 | 下一个有效交易日上涨、下跌、横盘的概率 |
| 5 日方向 | 未来 5 个有效交易日上涨、下跌、横盘的概率 |
| 20 日收益区间 | 未来 20 个有效交易日的 P10/P50/P90 收益区间 |
| 20 日最大回撤风险 | 未来 20 个有效交易日发生较大回撤的风险 |

回撤风险不是下跌概率，方向概率也不是买卖信号。

## 2. 第一次安装

在项目根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -e ".[dev,documents,train]"
npm install
```

训练依赖安装失败时，页面和基础 API 仍能运行；对应训练任务会显示 `unavailable`，不要手工更改状态。

## 3. 启动网页

```bash
npm run dev:research-platform
```

终端会打印实际端口。通常使用：

- 工作台：<http://127.0.0.1:5173>
- API 文档：<http://127.0.0.1:8000/docs>

若 5173 被占用，日志会显示新的网页端口；请以日志为准。停止服务时，在启动它的终端按 `Ctrl+C`。

## 4. 怎么看网页

打开后默认是 **A 股研究模式**。按以下顺序阅读：

1. 顶部：确认研究模式、数据截至时间与来源。
2. 研究对象：选择股票或 ETF。
3. 四任务卡：查看 1 日方向、5 日方向、20 日收益和 20 日回撤。
4. 数据质量：查看覆盖率、数据源、缓存、事件状态和降级原因。
5. Shadow：查看已冻结预测数和 T+1/T+5/T+20/T+60 回填进度。
6. 证据与治理：需要追溯时查看模型版本、快照 hash、roster 和正式模式阻断原因。

| 状态 | 含义 | 页面应如何理解 |
| --- | --- | --- |
| `research_only` | 公开数据的研究结果 | 仅供观察和比较 |
| `exploratory` | 产物已生成，但严格研究指标未完全通过 | 仅作实验观察 |
| `unavailable` | 缺模型、报告或必要数据 | 查看具体缺失原因 |
| `abstain` | 覆盖不足、数据冲突、数据过期或模型分歧过大 | “证据不足，暂不预测”是正确结果 |
| `blocked` | 正式授权/PIT 证据缺失 | 不影响研究模式 |

页面不应出现“买入”“卖出”“必涨”“必跌”或“实时交易级行情”。

## 5. 运行一次完整研究

完整入口：

```bash
python3 scripts/run_cn_research_demo.py
```

它依次执行：公开数据采集 → 数据质量审计 → 研究快照 → 四任务训练/评估 → 模型清单 → 推理 → Shadow 冻结 → 后端验收报告。

第一次建议先运行轻量 smoke，确认本机环境与网络：

```bash
python3 scripts/run_cn_research_demo.py \
  --profile smoke \
  --max-symbols 20 \
  --max-equities 20 \
  --minimum-equities 1 \
  --minimum-cohort-symbols 1 \
  --minimum-history-sessions 60 \
  --symbols-per-cohort 1 \
  --skip-sequence-challengers
```

完成后查看：

```text
artifacts/cn_research_demo/latest.json
artifacts/cn_research_demo/latest-backend-acceptance.json
```

重点确认四任务各自的状态和原因、数据来源、Shadow 是否冻结，以及 `data_tier=research_pit`、`deployment_ready=false`。`partial` 不一定是错误：免费源限流、历史不足或模型门禁未通过时，系统应如实标记不可用或拒答。

## 6. 结果在哪里

| 位置 | 内容 |
| --- | --- |
| `artifacts/cn_research_demo/` | 每次运行与后端验收报告 |
| `artifacts/free_research_models/` | 四任务 manifest、模型、评估与 hash |
| `artifacts/research_shadow/` | 冻结预测与追加回填 |
| `artifacts/free_research_coverage.json` | 数据源覆盖、失败、降级与冲突账本 |
| `var/cn-research/` | 本地数据、cursor 和目录数据库 |

需要回填 Shadow 时：

```bash
python3 scripts/backfill_research_shadow.py \
  --session-id <Shadow 会话 ID> \
  --standard-manifest <标准层 manifest 路径>
```

回填只新增结果，不会改写已冻结预测。

## 常见问题

**显示“证据不足，暂不预测”**：这是 `abstain`。展开任务卡，查看数据过期、覆盖不足、Provider 冲突、输入异常或模型分歧等原因。

**所有任务显示 `unavailable`**：先运行第 5 步 smoke，再打开 `artifacts/cn_research_demo/latest.json`，确认缺的是数据、样本、模型还是评估报告。

**为什么正式模式始终是 `blocked`**：免费公开数据不能证明商业授权、SLA、历史可见时间与正式 PIT revision。正式模式必须保持阻断，但研究模式仍可工作。

**怎样确认代码正常**：执行：

```bash
python3 -m pytest -q
npm test -- --run --no-file-parallelism
npm run build:workbench
git diff --check
```
